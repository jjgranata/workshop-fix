
# Project Plan

**Author**: Team097 - Troy Lamphere, Max Yu, Ethan McDermott, Joshua Granata

## 1 Introduction

This product is a job comparison app, which allows users to enter, rank, and select different jobs based on their preferences.

## 2 Process Description
---
- Activity Name: Architect Design
- Activity Description: Team considers use cases laid out in project description and creates intelligent design used to draft system accordingly.
- Entrance Criteria: Assignment 5 Document
- Exit Criteria: UML Diagrams + Team-based UML Diagram. Team should be able to review over use cases and satisfy all parts and paths in Team-based UML document.
---
- Activity Name: Weekly Planning
- Activity Description: Team summarizes what work will be programmed for the week
- Entrance Critera: Project needs from architecture
- Exit Criteria: A set of deliverables the team has committed to, each choosing a task.
---
- Activity Name: Software Development
- Activity Description: Team programs work used in application
- Entrance Criteria: A set of deliverables the team has committed to
- Exit Criteria: Code that satisfies acceptance criteria of user story (will be verified by QE)
---
- Activity Name: Quality Assurance Testing
- Activity Description: Users test functionality of programmed code to ensure it works as expected
- Entrance Criteria: Code merged in GitHub
- Exit Criteria: Someone from the team ensures the product works as expected. Also writing tests
